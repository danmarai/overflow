How it works

Three sources on the laptop, one destination on the stick. Same path on both sides, so putting anything back is a plain copy.

Idle = no file under 1 MB modified. Big media is ignored, so clones and copies can't fool it.

Built to not lose your data

  • Marker file. The stick carries an empty .overflow-stick file. No marker, no move. It can't write into an empty mount point or the wrong drive.
  • Verify, then delete. Files are copied, compared byte for byte, then removed. Folders are checksummed with rsync. A failed check keeps the original.
  • Databases and keys stay home. SQLite stores, settings, credentials and anything you list in FOLDER_KEEP are never candidates.
  • Dry run by default. The script shows what it would do unless you pass --run. Everything is logged on the stick.
  • Plain files, plain paths. No database, no proprietary format. Unplug the stick and read it on any Mac.

Install in sixty seconds

Format any stick as APFS and name it Overflow. Clone the repo, run the installer, pick your sources in one config file. The menu bar app, the weekly job and the archive script all land in the right places.

git clone https://github.com/<you>/overflow
cd overflow && ./install.sh
# then edit, if you like:
#   ~/Library/Application Support/Overflow/config.zsh
